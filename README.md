# 📖 About The Project

**GlisHR** is a web-based HR Recruitment Management System designed to simplify the recruitment process for organizations. The application provides dedicated portals for **Admin**, **HR**, and **Job Seekers**, where each user gets access based on their assigned role.

The system enables HR teams to create job openings, manage applicants, review resumes, and monitor recruitment activities, while candidates can search for jobs, apply online, and upload their resumes.

The project follows the **MVC Architecture** using **Java Servlets**, **JSP**, **JDBC**, and **MySQL**, providing a clean separation between presentation, business logic, and database operations.
